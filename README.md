# comparador

## Backend contábil

### Requisitos

- Python 3.10+

### Instalação

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Executar

```bash
python app.py
```

### Endpoints

- `GET /health`
- `POST /api/projections`
- `POST /api/tax-estimate`
- `POST /api/summary`
